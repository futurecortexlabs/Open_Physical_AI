# 共通USDアセットの準備

[シリーズ一覧](../README.md)へ戻る。

各サンプルは、FANUC CRX-20iA/L、Robotiq 2F-85、RealSense D455を配置したカスタムUSDシーンを読み込みます。USD本体はリポジトリに同梱せず、`.gitignore`で除外しています。

自分が利用できるモデルを各提供元から用意し、参照先も解決できる状態にしてください。組み合わせに使った元モデルの配布場所や、再配布の可否を本リポジトリが保証するものではありません。

## 配置するファイル

```text
assets/crx20ia_l+Robotiq_2F_85_edit+rsd455.usd
```

これは#01〜#04に共通の既定ファイル名です。名前を合わせただけでは動きません。Prim階層・関節・ドライブ設定を、各スクリプトの設定と合わせる必要があります。

USDには別のUSDへのreferenceやpayloadが含まれる場合があります。ルートファイルだけをコピーしても、参照するモデル・マテリアル・テクスチャが無ければ再現できません。参照先がクラウドなら通信環境、ローカルならそのファイル一式が必要です。

## #04で使用するシーン構成

| 項目 | コードの前提 |
|---|---|
| ロボットPrim | `/World/crx20ia_l` |
| 手先フレーム | 下記の `grip_frame_path` |
| グリッパーの制御関節 | `finger_joint` |
| アームDOF | 6。取得したDOF配列の先頭6個をアームとして使用 |
| 関節制御 | 位置目標へ追従するドライブ設定 |
| 座標と寸法 | コード側はメートル・Z上方向を想定 |
| 初期姿勢 | USDから読み込んだ姿勢をリセット基準に使用 |

```python
grip_frame_path = (
    "/World/crx20ia_l/J6_link/flange/ee_link/Robotiq_2F_85_edit"
    "/Robotiq_2F_85/base_link/grip_frame"
)
```

学習用IK教師は、この手先フレームの親に当たるグリッパー基部の絶対パスを、Articulationのリンク一覧から探します。教師のJacobian行インデックスには固定ベースの構成を想定しています。別ロボットや異なる関節順では、本体の調整と再検証が必要です。

カメラ関連のPrimや設定は回ごとに異なります。#02・#03は、それぞれのREADMEと設定クラスも確認してください。#04ではカメラ画像を方策の入力に使いません。

## 準備の確認項目

- ロボットがArticulationとして認識され、期待する関節・リンクを取得できる。
- 手先の位置・向きが正しく取得できる。
- アーム関節へ位置目標を送ると、想定方向へ追従する。
- グリッパーの指が開閉し、ワークと接触する。
- リンクの剛体、衝突形状、質量、関節ドライブに関する警告を確認する。
- 警告があるまま試行する場合は、ログと実際の挙動を記録する。

別ファイル名へ変更するときは、各スクリプトの設定生成関数でUSDパスを変更します。別のPrim階層では `RobotConfig` のパス等も変更します。コード側の制御スケールを変えたら、#04の学習済みモデルをそのまま流用できるとは限りません。

## ローカルUSDで確認した警告

2026-09-02の#04検証では、`/World/crx20ia_l/J6_link/rsd455/RSD455` の剛体検索エラーが出ました。同じ環境でGPU物理の到達挙動が不良だったため、#04では検証済みのCPU物理を既定にしています。

この警告がGPU物理の問題の原因だと確認したわけではありません。警告を消す目的だけで `RigidBodyAPI` を追加・削除せず、リンク階層や物理的な意味を確認してから、別途比較試験を行ってください。[検証記録](../04_rl_control/docs/validation.md)に観測事実と未確定事項を分けて記載しています。

## ワークについて

ロボット以外のワークは各回のスクリプトが準備します。

- #01・#02・#04：`UsdGeom.Cube`で赤いキューブを作成。
- #03：Isaac Simの標準アセットを実行時に参照。アセットサーバーまたは設定済みのローカル参照先へのアクセスが必要。

## 配布上の注意

USD本体と参照先アセットは公開対象に含めていません。元モデル、マテリアル、テクスチャ、ロゴ等の利用条件はそれぞれ確認してください。動画や静止画の公開についても、元アセットの利用条件を別途確認する前提です。[公開前チェック](../docs/publishing.md)を参照してください。
