# #02 カメラで物体検出ピッキング

#01 ではキューブの位置を**座標で教えて**いました。#02 では **トップダウンの RGB-D カメラで赤いキューブを見つけて**、その世界座標を推定してからつかみに行きます。

ロボットを動かす土台（Jacobian IK・状態機械・往復ループ）は **#01 と同一**です。変わったのは「キューブの位置をどこから得るか」だけ。

## 検出のしくみ（色 → 3D）

機械学習も OpenCV も使わず、numpy だけで完結します。

1. **撮る** … ワークスペースの真上に置いた自前カメラで RGB 画像と深度画像を取得
2. **赤を抜く** … `R が高く G・B が低い` ピクセルをマスクして、重心 (u, v) を中央値で求める
3. **深度を読む** … 重心まわりの深度 d を中央値で取る（ノイズに強い）
4. **逆投影する** … `(u, v, d)` を自前のピンホールモデルで世界座標へ変換

> 4 の逆投影は外部ヘルパに頼らず自分で計算しています（`CubeDetector.detect`）。
> カメラ座標での光線方向を作り、深度 d を掛けてからカメラの世界姿勢で回す、それだけ：
>
> ```
> x_c = (u - cx)/fx * d      # 右方向(+X)
> y_c = -(v - cy)/fx * d     # 上方向(+Y)。画像の v は下向きなので符号反転
> z_c = -d                   # 前方は -Z（USDカメラ規約）
> world = cam_pos + R @ [x_c, y_c, z_c]
> ```
>
> `fx = focal_length × 幅 / horizontal_aperture`（ピクセル単位の焦点距離）。
> 縦横のピクセルを正方にそろえるため、縦アパーチャを解像度比で設定しているのがポイント
> （やらないと Y 方向だけ倍率がずれて、拾う位置が縦にずれます）。

## #01 からの差分

| 項目 | #01 | #02 |
|---|---|---|
| キューブ位置 | 真値を直接読む | **カメラで検出** |
| 追加要素 | — | `CameraConfig` / `CubeDetector` / 観測ステージ |
| IK・フェーズ | \<同じ\> | \<同じ\> |

各サイクルの頭に **観測ステージ** を挟み、アームを一旦ホーム姿勢へ戻して視界を確保してから検出します。検出に失敗した場合（オクルージョン等）は、**既知座標へフォールバック**して停止せずに動き続けます。

## 調整ポイント

| 設定（`CameraConfig`） | 意味 |
|---|---|
| `position` | 見下ろしカメラの設置位置（ワークスペースの真上） |
| `resolution` | 解像度。上げると小さいキューブも検出しやすい |
| `red_min` / `red_dominance` | 赤とみなす条件。`R>red_min` かつ `R` が `G,B` より `red_dominance` 以上大きいこと（照明に強い相対判定） |
| `min_pixels` | これ未満のマスクは「検出なし」とみなす |

### つまずきポイント

- **検出されない** → `debug: True` のログの「最赤画素 RGB」を確認。R が G,B より十分大きくなければ `red_dominance` を下げる。全体的に暗いなら `red_min` を下げる。`min_pixels` や `resolution` も調整。
- **位置がズレる（別の場所を拾う）** → `debug` ログの `world=(...)` が実際のキューブ座標と合うか確認。合わない場合はカメラの向き（既定は真下＝単位クォータニオン）と `focal_length` / `horizontal_aperture` を確認。縦だけズレるなら縦アパーチャ（正方ピクセル化）が効いていない可能性。
- **2周目以降で未検出になりがち** → アームがキューブを隠している可能性。観測ステージの `observe_frames` を増やすか、カメラ位置を見直す。

> ⚠️ **カメラ API について**：本サンプルは `isaacsim.sensors.camera.Camera` を使っています。お使いの Isaac Sim のビルドで API 名やメソッドが異なる場合は、`CubeDetector.setup / initialize / detect` の3か所を調整してください（ここに検出処理は隔離してあります）。
