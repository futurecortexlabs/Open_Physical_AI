# Open Physical AI

NVIDIA **Isaac Sim** 上で、ロボットアームに「物をつかんで置く」を教えるための最小構成サンプル集です。
カメラも機械学習も使わず、**逆運動学（IK）と状態機械（ステートマシン）だけ**でピック＆プレースを実装しています。

物理AIの一番の土台である「アームを狙った座標へ動かす」を、ライブラリのブラックボックスに頼らず自分の手で書いて学ぶことを目的にしています。

---

## デモ：かんたんピッキング

固定座標に置いた赤いキューブを、ロボットがつかんで別の場所へ置く動作を **往復し続ける** デモです。

- **ロボット**：FANUC CRX-20iA/L（協働ロボットアーム）
- **グリッパー**：Robotiq 2F-85（2本指）
- **前提**：キューブの位置は既知（座標で与える）。カメラ・学習なし。

7つのフェーズを順番に実行します：

| # | フェーズ | やること | グリッパー |
|---|---|---|---|
| 0 | 上空へ移動 | キューブの真上へ | 開 |
| 1 | 下降して接近 | つかむ高さまで降りる | 開 |
| 2 | 把持 | その場で指を閉じる | 閉じる |
| 3 | 持ち上げ | 真上へ持ち上げる | 閉 |
| 4 | 搬送 | 置き場所の上空へ運ぶ | 閉 |
| 5 | 下降して設置 | 保持したまま降ろす | 閉 |
| 6 | 離す | その場で指を開く | 開 |

完了後は拾い先／置き先を入れ替えて先頭フェーズへ戻り、A地点⇄B地点を往復します。

## しくみ

### 状態機械（ステートマシン）

`SimplePickPlace` が「今どのフェーズか」を管理し、目標に到達（または一定時間経過）したら次のフェーズへ進みます。各フェーズは表示名・グリッパー開閉・タイムアウトを持ちます（`PHASE_SPECS`）。

> 「下降」と「離す」を別フェーズに分けているのがポイント。ひとつにすると着地前に手を離してキューブを落とすため、**降ろしきってから離す**順にしています。

### 逆運動学（IK）

「手先を座標 (x, y, z) へ動かしたい」を「各関節をどう動かすか」に変換する部分です。`JacobianIK` が **ヤコビアン＋減衰最小二乗法（DLS）** で1ステップずつ解きます。

1. 現在の手先位置・姿勢から目標との誤差（位置3＋姿勢3）を作る
2. ヤコビアン J（関節速度→手先速度の対応表）を取得する
3. `dq = Jᵀ (J Jᵀ + λ²I)⁻¹ e` で「誤差を減らす関節変化」を逆算する
4. 動きすぎないよう上限でクリップして関節目標に送る

`λ²I`（ダンピング項）を足すことで、特異点近傍でも計算が発散せず安定して動きます。

## 設定を変えて遊ぶ

パラメータは種類ごとに `dataclass` へまとめてあります（`simple_picking.py` 上部）。まずは以下を書き換えるのが分かりやすいです。

```python
@dataclass(frozen=True)
class SceneConfig:
    cube_size: float = 0.06
    cube_position   = np.array([0.72, 0.0, 0.03])   # つかむ場所
    place_position  = np.array([0.50, 0.32, 0.03])  # 置く場所
    above_height: float = 0.30                      # 上空へ逃がす高さ
```

| 設定 | 意味 |
|---|---|
| `SceneConfig.cube_position` / `place_position` | つかむ場所・置く場所 |
| `ControlConfig.loop` | `False` で1サイクル実行して停止 |
| `ControlConfig.setpoint_speed` | 追従点を進める速さ（小さいほどなめらか） |
| `IKConfig.max_joint_delta` | 1ステップの関節変化上限（小さいほど穏やか） |

### つまずきポイント

- 腕が目標に届かない → `above_height` を下げる／`cube_position` をロボットに近づける
- つかむ前に落とす → フェーズ5と6が分かれているか確認
- 動きがカクつく → `setpoint_speed` を小さく
- 急に暴れる → `max_joint_delta` を小さく
